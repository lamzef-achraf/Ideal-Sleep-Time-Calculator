# 🛌 Ideal Sleep Time Calculator

This is a simple and interactive web app that helps users calculate the best time to go to sleep based on a desired wake-up time. It uses the "sleep cycle" principle, where each sleep cycle lasts approximately 90 minutes.

## 🔧 Built With

- HTML
- CSS
- JavaScript

## ✨ Features

- User inputs wake-up time
- Calculates ideal sleep times based on 90-minute sleep cycles
- Simple, mobile-friendly design

## 🚀 How to Use

1. Select your desired wake-up time
2. Click "Calculate"
3. Get 3 recommended sleep times
4. Pick one and enjoy better sleep!
